# Digital Chaos Magick Servitor Manager

## What this is

A digital toolset for creating, charging, and managing chaos magick servitors. It automates the mundane aspects of servitor maintenance while keeping the practitioner's intent and intuition at the core.

## Tech

- Python
- Tkinter (GUI)
- Pillow (Image handling)
- JSON (Storage)

## Run locally

```bash
pip install -r requirements.txt
python -m servitor.gui
```
